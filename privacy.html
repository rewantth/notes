Job Tracker: Privacy Policy

Last updated: 19 November 2026

Job Tracker is a personal, single-user tool. It is built and used only by its owner to keep track of the owner's own job applications. It is not offered to the public and has no other users.

What it accesses

With the owner's permission it reads the owner's own Gmail messages using the read-only scope (gmail.readonly). It looks for emails about job applications, such as confirmations, interview invitations and rejections.

What it does with the data

  • From each relevant email it extracts the company, role, date, job portal and application status.
  • The results are encrypted with a passphrase known only to the owner and published as an encrypted file. Only someone with the passphrase can read it.
  • Email content is processed temporarily on GitHub Actions to produce that file and is not stored, sold, shared or used for advertising.
  • No data is transferred to or shared with any third party, and no human reads the emails.

Google API Services User Data Policy

Job Tracker's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.
